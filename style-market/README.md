# Style Market — интернет-магазин одежды (HTML + CSS + JavaScript)

Учебный проект: «Проектирование информационной архитектуры веб-сайта и создание интерфейса с помощью HTML/CSS».

## Как открыть
Откройте файл `index.html` в любом браузере (двойной щелчок). Сервер не нужен.

## Структура папки
```
style-market/
├── index.html        — Главная
├── catalog.html      — Каталог (товары, поиск, фильтры, таблица размеров)
├── cart.html         — Корзина и оформление заказа
├── account.html      — Личный кабинет (вход, регистрация, история заказов)
├── contacts.html     — Контакты, форма обратной связи, FAQ
├── style.css         — Все стили (Flexbox, Grid, :hover, @media)
├── script.js         — JavaScript: корзина, поиск, фильтры, модальное окно, формы
├── ARCHITECTURE.md   — Информационная архитектура, Sitemap, схема взаимодействия
└── images/           — Изображения товаров (SVG)
```

## Что умеет сайт
- Переход между 5 разделами (меню + бургер-меню на телефоне)
- Поиск товаров (с главной и в каталоге), фильтр по категориям, сортировка
- Окно «Подробнее» с выбором размера
- Корзина: добавление, количество, удаление, промокод **STYLE10** (−10%), расчёт доставки
- Оформление заказа с проверкой полей формы
- Регистрация/вход, бонусы, история заказов (данные сохраняются в localStorage браузера)
- Форма обратной связи со счётчиком символов, подписка, раскрывающиеся FAQ
